# Contributing

Thanks for wanting to help! A few simple rules:

1. **Keep it simple for normal users.** No technical words on screen, no extra steps.
2. **Keep the scope small.** One fix or one feature per pull request.
3. **Never include secrets.** No API keys, passwords or personal data in code, issues or screenshots.
4. **Test it.** Try a real YouTube link end-to-end (captions + no-caption) before opening a PR, and say how you tested it.

## How to contribute

1. Fork the repo.
2. Create a branch: `git checkout -b my-improvement`
3. Make your change.
4. Open a pull request describing what changed and how you tested it.
